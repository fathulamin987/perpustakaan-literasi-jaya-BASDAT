MySQL XAMPP Belum Aktif

Aplikasi tidak dapat terhubung ke server basis data MySQL di port 3306.

Langkah Mengaktifkan:
  1. Buka aplikasi XAMPP Control Panel di komputer Anda.
  2. Cari modul MySQL, lalu klik tombol Start.
  3. Pastikan statusnya berubah menjadi hijau dan menunjukkan port 3306.
  4. Setelah aktif, klik tombol muat ulang di bawah.
